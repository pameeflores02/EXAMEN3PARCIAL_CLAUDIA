# 🧠 Clasificador de Objetos con IA en la Nube
**By: Claudia Aguilar** — Examen 3er Parcial, Computación en la Nube

## ¿Qué hace?
App web que identifica objetos en imágenes usando un modelo CNN
entrenado en Google Colab con el dataset CIFAR-10 (10 clases).

## ¿Cómo usarla?
1. Abre la URL pública.
2. Sube una imagen o toma una foto con la cámara.
3. La app muestra el objeto detectado y su nivel de confianza.

## Tecnologías
Google Colab (entrenamiento) · TensorFlow/Keras (CNN) · CIFAR-10 (dataset)
· Streamlit (app) · Streamlit Cloud (despliegue) · GitHub (código)
